# Выполненная практика «Чирк»

Решены шаги 1–6, включая все усложнения. Ответы на вопросы находятся в комментариях рядом с решениями. Для каждого шага сделан отдельный коммит. Исходное условие сохранено в README.md.

## Запуск

Откройте репозиторий в Codespaces или VS Code Dev Containers и выполните:

```sh
dotnet run
```

Используются .NET 10, EF Core/Npgsql 10 и PostgreSQL 17. Конфигурация контейнеров лежит в `.devcontainer`. Вне контейнеров PostgreSQL должен быть доступен на localhost:5432, пользователь и учебный пароль — postgres.

Программа удаляет и создаёт заново только учебную базу `match_shop` при каждом запуске. Не используйте её с рабочей базой магазина.

## Результаты проверки

Проверено двумя последовательными запусками в локальных Docker-контейнерах. Codespaces недоступен для ранее проверенного аккаунта (`Usage not allowed`), поэтому выполнение в Codespaces не заявляется.

- После заполнения: 5 покупателей, 5 товаров, 4 заказа.
- У Ивана 2 заказа, у Сергея 0.
- Выручка до повышения цен: 1320,00 ₽.
- Товаров в наличии до изменений: 4.
- Цены увеличены на 10%, у кухонных спичек остаток установлен в 0.
- Успешный заказ на 5 коробок: 5 заказов, остаток бытовых спичек 95.
- При попытке заказать 96 коробок: отказ, данные не изменились.
- После удаления: 3 покупателя, 3 товара, 2 заказа.
- Повторный запуск даёт те же результаты.

Полный журнал SQL и вывода программы: `verification/run.log`.

Данные покупателей учебные. Для настоящего магазина нужно сохранять цену покупки в заказе, защищать остаток от конкурентных изменений и сохранять историю вместо каскадного удаления. Эти ограничения пояснены в коде.
